# CPI Hub User Guide

## Introduction

Welcome to the Contextual Project Intelligence (CPI) Hub - your centralized platform for project intelligence and analytics. This guide will help you get started with the CPI Hub and make the most of its features.

## Getting Started

### Creating an Account

To access the CPI Hub, you'll need to create an account:

1. Navigate to the login page at `/auth`
2. Click on "Register" to create a new account
3. Fill in your details including username, full name, email, and password
4. Click "Create Account" to complete registration

### Logging In

Once you have an account:

1. Navigate to the login page at `/auth`
2. Enter your username and password
3. Click "Sign In" to access the dashboard

## Dashboard Overview

The dashboard provides a high-level overview of your projects and activities:

- **Project Progress Chart**: Visualizes the progress of your active projects
- **Recent Activities**: Shows recent activities across your projects
- **Project Insights**: Displays AI-generated insights about your projects
- **Relationship Network**: Visualizes relationships between different project elements

## Projects

### Viewing Projects

The Projects page displays all your projects with key information:

- Project name and description
- Current status
- Progress percentage
- Associated teams

### Creating a New Project

To create a new project:

1. Navigate to the Projects page
2. Click "Create New Project"
3. Fill in the project details:
   - Name (required)
   - Description
   - Status (default: active)
   - Icon (optional)
4. Click "Create Project" to save

### Managing a Project

From a project's detail page, you can:

- Update project information
- View and manage tasks
- View and manage documents
- See team assignments
- Track project activities
- Explore relationships with other projects

## Teams

### Viewing Teams

The Teams page displays all teams across your organization:

- Team name and description
- Team members
- Associated projects

### Creating a New Team

To create a new team:

1. Navigate to the Teams page
2. Click "Create New Team"
3. Fill in the team details:
   - Name (required)
   - Description
   - Icon (optional)
4. Add team members by selecting users from the dropdown
5. Click "Create Team" to save

### Managing Team Members

From a team's detail page, you can:

- Add or remove team members
- Assign team members to projects
- Set member roles

## Tasks

### Viewing Tasks

Tasks can be viewed:

- On the Dashboard (tasks assigned to you)
- On a Project's detail page (all tasks for that project)
- On a Team's detail page (tasks assigned to the team)

### Creating a New Task

To create a new task:

1. Navigate to a project's detail page
2. Click "Add Task"
3. Fill in the task details:
   - Title (required)
   - Description
   - Status
   - Assigned team
   - Assigned user
   - Due date
4. Click "Create Task" to save

### Updating Task Status

To update a task's status:

1. Navigate to the task
2. Click on the status dropdown
3. Select the new status
4. The change is automatically saved

## Documents

### Viewing Documents

The Documents page displays all documents across your projects, or you can view documents specific to a project from its detail page.

### Uploading a Document

To upload a new document:

1. Navigate to the Documents page or a project's documents section
2. Click "Upload Document"
3. Fill in the document details:
   - Title (required)
   - File (upload from your computer)
   - Description (optional)
   - Project association
4. Click "Upload" to save

### Viewing Document Content

To view a document's content:

1. Navigate to the Documents page
2. Click on the document title
3. The document will open in the document viewer

## AI-Powered Insights

### Viewing Insights

AI-generated insights are available:

- On the Dashboard (general insights)
- On a Project's detail page (project-specific insights)

### Generating New Insights

The system automatically generates insights based on project activities, but you can request new insights:

1. Navigate to a project's detail page
2. Click "Generate Insights"
3. The system will analyze project data and generate new insights

## Integrations

### Available Integrations

CPI Hub supports integrations with various third-party tools:

- Slack for team communication
- GitHub for code repositories
- JIRA for project management
- Google Workspace for documents

### Setting Up an Integration

To set up a new integration:

1. Navigate to the Integrations page
2. Click on the integration you want to set up
3. Follow the on-screen instructions to authorize and configure the integration
4. Once configured, the integration will appear in your active integrations list

## Account Settings

### Updating Profile Information

To update your profile:

1. Click on your avatar in the top right corner
2. Select "Profile Settings"
3. Update your information as needed
4. Click "Save Changes"

### Changing Password

To change your password:

1. Navigate to Profile Settings
2. Click "Change Password"
3. Enter your current password and new password
4. Click "Update Password"

## Getting Help

If you encounter any issues or have questions:

- Check the FAQ section in the Help menu
- Use the "Contact Support" option in the Help menu
- Refer to the administrator documentation for more advanced issues

## Troubleshooting

### Common Issues

- **Can't log in**: Ensure your username and password are correct. Use the "Forgot Password" link if needed.
- **Projects not showing**: Check your permissions with your administrator.
- **Integration not working**: Verify your API keys and permissions for the integrated service.
- **Slow performance**: Try refreshing the page or clearing your browser cache.

### Error Messages

If you encounter an error message, note the error code and description. These will help support staff diagnose the issue if you need to contact them.

## Updates and New Features

The CPI Hub is continually being improved. Check the "What's New" section in the Help menu for information about recent updates and new features.
